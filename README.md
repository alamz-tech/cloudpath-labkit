# CloudPath labkit

Verification scripts for CloudPath practice labs. Learners run these in their
lab terminal (e.g. a Killercoda playground) using the one-line command their
CloudPath coach sends them, for example:

```
curl -sSL https://raw.githubusercontent.com/alamz-tech/cloudpath-labkit/main/verify-day-01.sh | bash -s <YOUR-CODE>
```

Each script checks your work locally and prints a short `CP-…` result line that
you paste back to the coach. The scripts don't upload anything themselves.

> These are generated from the CloudPath curriculum. Verification is
> pilot-grade and assistive — final milestone labs are graded from your public
> GitHub repo.
